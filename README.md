# Sahjanand School of Achievers — Website Redesign

This is the modernized, premium redesign of the Sahjanand School of Achievers website, featuring a traditional Indian palace-style gateway transition that flows into a highly contemporary, responsive academic dashboard.

---

## 🎨 Design Theme & Aesthetics

- **Brand Primary Color**: **Morpankh Teal-Blue (`#0C5B70`)** — inspired by the majestic and wise peacock feather neck hue, bringing traditional Indian heritage to a digital screen.
- **Brand Accent Color**: **Amber Gold (`#E5A93B` / `#D97706`)** — representing victory, success, and royal hospitality.
- **Backgrounds**: A premium **Ivory / Off-White (`#FAF9F6`)** background that feels softer and more prestigious than pure white.
- **Typography Scale**:
  - **Headlines & Greetings**: *Playfair Display* (Serif) — conveying classical prestige, literary authority, and establish heritage.
  - **Body & Controls**: *Manrope* (Sans-serif) — clean, geometric, and highly readable.

---

## 🚀 Key Features

1. **Namaste Portal (`#welcome-portal`)**: 
   - Welcomes the user with a folded-hands **Namaste Mudra** SVG graphic.
   - Shows the traditional welcoming quote *"Atithi Devo Bhava"*.
   - Splits into two campus archway gateways (**Chiloda Campus** and **Sargasan Campus**).
2. **Respectful Mudra Guidance**: 
   - A left-pointing gesture guides visitors towards Chiloda.
   - A right-pointing gesture guides visitors towards Sargasan.
   - Hovering over a card activates pointing motions on these hand indicators.
3. **Majestic Portal Zoom**: 
   - Clicking a card zooms it in to fill the screen (walking through the gates), while the other card shrinks and fades out, revealing the main portal.
4. **Modern Dashboard (`#main-portal`)**:
   - Floating sticky navigation bar with active page links.
   - Bento-box visual hero container showcasing modern campus labs and libraries.
   - Metric counters that dynamically count up on scroll (25+ Subjects, 11+ Labs, 140+ Teachers, 2100+ Students).
   - Profiles of honorable trustees, GSEB curricula breakdown, a filterable campus gallery, and a built-in parent enquiry portal.

## 💻 How to Run Locally

### Option 1: Direct File Launch (No setup needed)
1. Open the project folder: `c:\Project_AI\school_achievers\`
2. Double-click or open `index.html` in any web browser (Chrome, Edge, Safari, Firefox).
3. Choose a campus to enter and test the animated transition!

### Option 2: Run via Local Dev Server (Recommended for development)
We've integrated a Vite-powered development server for high-performance and hot-reloading:
1. Ensure Node.js is installed.
2. In your terminal inside the project directory, install dependencies:
   ```bash
   npm install
   ```
3. Start the dev server:
   ```bash
   npm run dev
   ```
4. Access the site via the local address printed (typically `http://localhost:5173`).
